# KaiL AI 2 </>

A minimal, cyberpunk-inspired productivity dashboard designed to keep full control over workflows, stats, and payouts. Built from mobile.

##  Key Features
- **Main Dashboard:** Fast access to tools, credit balance, and active session status.
- **User Stats:** Work time tracking, success rate, and tech stack distribution.
- **Payout Gateways:** Dedicated interfaces (PayPal, Personal Pay, Wise) with dynamic range sliders.
- **Level Progression:** Clear requirements and focus areas from Beginner to Expert.

## Tech Stack
- Vanilla HTML5 & CSS3 (Dynamic gradients, keyframe animations, responsive UI)
- Vanilla JavaScript (DOM manipulation, real-time range events)
- Built on mobile via Spck Editor.
